# System tests (`@ss/e2e`)

Tests that need two or more deployables: each product against the **real** Portal, in process, on one
MongoMemoryReplSet. They use only public entry points (`@ss/platform/testing`, `@ss/app-kit`, `@ss/app-kit/testing`,
`@ss/protocol` and each product's `./product` and `./routes`). This workspace is private, never deployed and has no
environment variables.

`tests/helpers.js` (`startSystem({ unit })`) starts the Portal with its real modules and a product on the real kit, each
on its own database, wired through one in-process fetch router; one clock drives both. `fixtures/notes` is a minimal
test product generated by `ss app init` (its `core/`, `server/`, `adapters/`, `schemas/`, `strings/`, `docs/`,
`manifest.json`, `openapi.json` and generated widget script), used by the contract tests (connect, tokens, reports,
statuses, tickets, dashboard launches, notices, websites and data rights). The product tests (`accounts`, `chat`,
`ecommerce`, `growth`, `notifications`, `payments`) run each shipped product against the Portal and the products it
works with.

```sh
pnpm --filter @ss/e2e check   # from the root; or `pnpm check` in this folder
```
