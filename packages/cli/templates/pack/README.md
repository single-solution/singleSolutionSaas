# {{name}}

SSPS v1 **element pack** generated by `ss app init`: front-end elements only, no server. The Loader mounts the Mode A
renderer (`ui/`), developers can build their own UI on the Mode B headless core (`headless/`), and state lives in the
Website Graph through the `client` the runtime passes in (`graph.session.*` scopes).

| Path                   | Purpose                                                                                                  |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| `manifest.json`        | SSPS manifest (kind `pack`: modes A/B only, no endpoints, graph/event-publish scopes only)               |
| `core/`                | pure domain logic                                                                                        |
| `headless/`            | `createNotes({ config, strings, client, emit })` → state, actions, subscribe, validate, strings, destroy |
| `ui/`                  | `render({ state, actions, strings, theme, slots, dom })` — design tokens only                            |
| `strings/`, `schemas/` | string catalog and feature schema                                                                        |
| `tests/`               | unit tests (Vitest)                                                                                      |

```sh
pnpm check        # format, lint, typecheck, unit tests with coverage (tooling from @ss/config)
ss app validate
ss pack build     # dist/pack: descriptor.json + bundled assets; upload the folder in Admin → Apps → Upload pack version
```
